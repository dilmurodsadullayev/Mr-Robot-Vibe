# Mr. Robot Vibe

> Hello, friend.

**Mr. Robot Vibe** is a fan-made interactive frontend experience inspired by the dark, cinematic, glitchy, and terminal-driven atmosphere of the TV series **Mr. Robot**.

The project recreates the feeling of entering a mysterious digital system through terminal interfaces, CRT effects, distorted typography, animations, and immersive interactions.

---

## Preview

> The system is waiting.

The visual experience will include:

- Dark cinematic interfaces
- Interactive terminal commands
- CRT monitor effects
- Glitch animations
- Scanlines and digital noise
- fsociety-inspired aesthetics
- Smooth transitions
- Responsive layouts
- Hidden interactions and easter eggs

The project is being built with:

## Project Goals

The goal of this project is not to recreate the official Mr. Robot website.

Instead, it is an experimental frontend project focused on:

- UI/UX design
- Creative frontend development
- React component architecture
- Animations
- Interactive experiences
- Terminal-inspired interfaces
- Cinematic web design

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/mr-robot-vibe.git
```

Enter the project:

```bash
cd mr-robot-vibe
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open the local Vite development URL in your browser.

Usually:

```text
http://localhost:5173
```

---

## Development

Check the project with ESLint:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```

Preview the production build:

